这个博客不需要服务器，也不需要买域名、去备案。它是怎么跑起来的？

## 静态网站

所有页面都是提前生成好的 HTML 文件，访客打开网址时，直接就能看到内容，没有后端、没有数据库。

## 托管在 GitHub Pages

把代码推到 GitHub 仓库，GitHub 会自动构建并发布，得到一个免费的网址 `yang7834.github.io`。

## 在线写作

博客挂了一个在线后台（Sveltia CMS），用 GitHub 账号登录后，可以在浏览器里直接写文章、传图片，保存后自动上线。

```js
// 一篇文章就是一个 Markdown 文件
title: "文章标题"
description: "一句话简介"
date: 2026-08-14
tags: ["标签"]
```

简单、免费、可控。
